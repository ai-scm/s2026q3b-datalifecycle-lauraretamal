# Ciclo de vida de los datos y análisis en AWS

Este repositorio contiene mapas mentales sobre las principales etapas del ciclo de vida de los datos y análisis en la nube de AWS.

## Etapas

1. **Etapa 2 – Montaje de datos**

   * Preparación y organización de los datos.
   * Amazon S3, Data Lake y bases de datos.
   * Clasificación y seguridad de los datos.

2. **Etapa 3 – Limpieza de datos**

   * Preparación y transformación de datos.
   * ETL y AWS Glue.
   * Amazon EMR y SageMaker Ground Truth.

3. **Etapa 4 – Análisis y visualización**

   * Análisis de datos preparados.
   * Amazon Athena y Amazon Redshift.
   * Data Warehouse y Data Lake.
   * Servicios de análisis, Machine Learning e IA.

4. **Etapa 5 – Archivado de datos**

   * Almacenamiento a largo plazo.
   * Amazon S3 Glacier y Glacier Deep Archive.
   * Clases de almacenamiento de S3.

5. **Seguridad de datos, privacidad y cumplimiento**

   * Confidencialidad, integridad y disponibilidad.
   * Control de acceso y privacidad.
   * Cifrado y gestión de claves.
   * Cumplimiento y seguridad en AWS.
